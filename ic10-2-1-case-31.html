2 Build a data dictionary

I used the dictionary to see what each question was called, which codes showed up, and how many answers were missing. Labels like savings rates (q7) and statement accuracy (q10) were clear. When I compared q8 and q9 with the questionnaire, I saw that they both had the statement-frequency label even though q8 asks about borrowing rates. I also spelled out short labels like “CU is prompt” for q32.

  • Nominal. Headquarters residence (q38) is a yes/no category. The service items (q13–q26) distinguish awareness and use. Their labels matter because 3 means Unaware, a valid response.
  • Ordinal. Statement accuracy (q10) and overall rating (q37) rank responses. The gap between categories is unknown. Statement frequency (q9) is ordered by frequency, with “About Right” in the middle.
  • Approximately interval for this exercise. The agreement items (q3–q6, q30–q34) are ordinal on their own. For alpha, factor analysis, and a justified mean score, I treated the 1–5 steps as roughly equal. The common agreement labels repeat across items, while the awareness and nonresponse labels need to be read explicitly.
Show the raw data dictionary 
make_dictionary <- function(df) {
  value_text <- function(x) {
    labels <- val_labels(x)
    if (length(labels) == 0) return("—")
    paste(paste(unname(labels), names(labels), sep = " = "), collapse = " / ")
  }
  data.frame(
    Variable = names(df),
    Label = vapply(df, function(x) {
      label <- attr(x, "label")
      if (is.null(label)) "—" else label
    }, character(1)),
    Class = vapply(df, function(x) class(x)[1], character(1)),
    Distinct = vapply(df, function(x) length(unique(x[!is.na(x)])), integer(1)),
    Observed = vapply(df, function(x) {
      paste(format(sort(unique(as.numeric(x))), trim = TRUE), collapse = ", ")
    }, character(1)),
    Missing = vapply(df, function(x) sum(is.na(x)), integer(1)),
    `Missing %` = vapply(df, function(x) round(mean(is.na(x)) * 100, 1), numeric(1)),
    `Value labels` = vapply(df, value_text, character(1)),
    check.names = FALSE
  )
}

3 Correct labels and check response codes

The agreement questions stored labels only for the endpoints. Codes 2, 3, and 4 needed the middle labels. The service questions were missing the label for 3 (Unaware), and the yes/no questions were missing the label for 3 (No answer). In the raw data, 3 actually appears as a nonresponse in q12. The raw label on q37 = 6 says “No Opinion.” Exhibit 31.2 calls it “No answer” for that scale, so I used the exhibit wording.

I kept the original file in data_raw and worked with a copy of the questionnaire columns. I left the two precomputed columns out of that copy because I couldn’t tell which questions went into them or how they handled missing answers.

I put the reversed scores in new columns so I could compare them with the originals. I used 6 - x for the five-point items and 5 - x for the four-point statement-accuracy item. A higher score means better accuracy in q10r and a better overall rating in q37r. In q7r and q8r, it just means a higher perceived rate. For borrowing, a higher rate can be worse for the member.

reverse_item <- function(x, maximum, label) {
  labels <- val_labels(x)
  labels <- labels[labels %in% seq_len(maximum)]
  reversed_labels <- sort(maximum + 1 - labels)
  haven::labelled(maximum + 1 - as.numeric(x), reversed_labels, label)
}
data$q7r <- reverse_item(data$q7, 5, "Savings rates (higher = higher rates)")
data$q8r <- reverse_item(data$q8, 5, "Borrowing rates (higher = higher rates)")
data$q10r <- reverse_item(data$q10, 4, "Statement accuracy (higher = better)")
data$q37r <- reverse_item(data$q37, 5, "Overall rating (higher = better)")

I kept the original coding for q9. “About Right” is code 3 and would stay in the middle after a reversal. For a yes/no measure of whether frequency was about right, I would use as.integer(as.numeric(data$q9) == 3), which gives 1 for About Right, 0 for other valid answers, and NA for blanks.

For the awareness exercise, I used 4 - x to make q13r–q26r. That puts Unaware at the low end and Aware and Have Used at the high end. 5 Evaluate the two candidate indexes

I used raw Cronbach’s alpha and a one-factor minimum residual model with no rotation. The corrected item-total correlation (r.drop) compares an item with the total of the other items. All 128 records had complete answers for both sets.

evaluate_items <- function(items, measure) {
  scores <- as.data.frame(lapply(data[items], as.numeric))
  scores <- scores[complete.cases(scores), , drop = FALSE]
  reliability <- psych::alpha(scores, check.keys = FALSE)
  factor <- psych::fa(scores, nfactors = 1, rotate = "none", fm = "minres")
  list(
    summary = data.frame(Measure = measure, N = nrow(scores),
                         `Raw alpha` = round(reliability$total$raw_alpha, 3),
                         check.names = FALSE),
    items = data.frame(Measure = measure, Item = items,
                       `Item-rest r` = round(reliability$item.stats$r.drop, 3),
                       `Factor loading` = round(as.numeric(factor$loadings[, 1]), 3),
                       Communality = round(factor$communality, 3),
                       check.names = FALSE)
  )
}

Employee proficiency. I got an alpha of 0.866. All four item-rest correlations were above 0.65, and the factor loadings ranged from 0.722 to 0.923. The questions all ask about how members experience the employees, so I averaged the four answers into one score.

Operational effectiveness. The alpha was lower at 0.539. All the item-rest correlations were positive, with q33 and q34 the lowest. The loadings also varied more, from 0.287 for q33 to 0.786 for q32. All five questions are worded in the same direction, but they ask about different things, like loan rates, privacy, and how quickly applications are processed. I kept the questions separate so I could look at the answers for each one.

6 Data preparation narrative and export

I used cross-tabs to check the reversed scores. The employee questions worked well enough together for one score, and I left the operations questions as individual items.

For the reliability and factor checks, I treated the steps on the agreement scale as roughly equal. That’s an assumption I made for this assignment. I also couldn’t tell from the file which missing entries had been left blank and which might have been coded as nonresponses earlier.
